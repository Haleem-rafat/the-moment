# The Moment | اللحظة

تجربة سينمائية لطلب إيد إسراء، عربي وإنجليزي، باحترام وعلى سنة الله ورسوله.

## التشغيل

```bash
npm install
npm run dev
```

افتح http://localhost:3000 — التقدم محفوظ في نفس التبويب، فعشان تبدأ من الأول افتح تبويب جديد.

## تعديل المحتوى (من غير ما تلمس أي كومبوننت)

| الملف | فيه إيه |
| --- | --- |
| `src/data/messages.ts` | كل كلمة على الشاشة، عربي (`ar`) وإنجليزي (`en`) |
| `src/data/memories.ts` | البراويز: الرسمة والعنوان والجملة بكل لغة |
| `src/data/proposal.ts` | مسارات ملفات الصوت |

## ملفات الصوت (`public/audio/`)

- `voice.mp3`: رسالتك بصوتك، 30–60 ثانية. بتتسمع قبل السؤال مباشرة، ولو الملف مش موجود المشهد بيتخطاها.
- `theme.mp3`: صوت الخلفية. لو الملف مش موجود، بتشتغل موسيقى هادية مولّدة بالكود، وتقدر تكتمها من زرار الصوت.

خلي الملفات صغيرة عشان النت الضعيف: `ffmpeg -i in.wav -b:a 64k -ac 1 voice.mp3` للصوت، و`-b:a 96k` للموسيقى.

## زرار واتساب

حط رقمك في `whatsappNumber` في `src/data/proposal.ts` (بكود الدولة ومن غير +)، وهيظهر زرار بعد الموافقة تبعتلك منه رقم والدها. لو سبته فاضي، الجملة بس هي اللي بتظهر.

## قبل ما تبعت اللينك

- سمّي مشروع Vercel اسم محايد زي `the-moment`، لأن الرابط بيظهر لها. ما تكتبش فيه `proposal` أو `wedding`.
- جرّب الرحلة كاملة على موبايل حقيقي.
- على الآيفون، زرار الصامت بيكتم الصوت. الشاشة الأولى بتنبهها لده.
